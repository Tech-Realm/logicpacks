# Contributing

Thanks for helping. LogicPacks is MIT licensed and contributions are welcome.

## Setup

See [README.md](./README.md#build-from-source) and
[docs/operations/development.md](./docs/operations/development.md) for the checkout, dev commands and tests.

## What to send

- Focused bug fixes, reliability and performance work, and tests are the easiest to review and merge.
- For a new feature or a behavior change, open an issue first so we can agree on the problem and scope.
- Keep pull requests small and about one thing. Explain what changed and why.

## Before you open a pull request

```bash
vp run typecheck
vp run test
vp fmt
```

Add or update tests with the change. Read [AGENTS.md](./AGENTS.md) for the conventions the codebase follows.

## Hosted services

Cloud, Talent, Apps and Packs and Enterprise are hosted services and are not part of this repository.

## Security

Do not report vulnerabilities in public issues. See [SECURITY.md](./SECURITY.md).
