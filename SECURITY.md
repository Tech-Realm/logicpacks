# Security policy

Please report suspected vulnerabilities privately. Use the contact details on https://logicpacks.io and
include steps to reproduce, the affected version and the impact you see. Do not open a public issue or
disclose the problem until we have had a reasonable chance to investigate and fix it.

We aim to acknowledge reports within a few days. Good-faith research that avoids harm to other people's
data and services is welcome.

Scope: the code in this repository and the hosted LogicPacks services. Secrets and signing keys are never
stored in this repository; if you find one, report it the same way.
